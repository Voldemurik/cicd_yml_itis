# Git-практика: CI/CD — почини, допиши, проверь

**Стартовая страница для студента.** Вам выдали ссылку в eLearn, и вы уже получили **собственный репозиторий — форк преподавательского шаблона**. Повторно форкать ничего не нужно. Работа ведётся в GitVerse, основная ветка называется `master`.

> **Важно:** исходный `student.yml` и часть Python-кода намеренно содержат ошибки. Первые красные запуски — нормальная часть задания. Не пытайтесь «починить» CI удалением реальных проверок.

## Что делать по порядку

1. **Создайте ветку** `student/<ваш_логин_в_GitVerse>` **от `master` в своём репозитории**. Ветка должна появиться на сервере GitVerse. Сработает `generate-variant.yml`, который запишет в эту ветку персональные `TASK.md` и `variant.json`.
2. **Прочитайте `TASK.md` и [подробную инструкцию](docs/STUDENT_GUIDE.md)**. Если файлов нет — проверьте запуск `01 - Assign task on branch creation` и правильность имени ветки.
3. **Исправьте код и `student.yml`**: Ruff, форматирование, pytest, статическая проверка из варианта, запуск программы с `REPORT_MODE` и сохранение `student-results`.
4. **Получите зелёный `02 - Student CI + artifact audit`**. Он запускается на push, результаты видны в CI/CD. В последней job `audit` должно быть `RESULT: PASS`.
5. **Отдельно настройте секрет** `READ_TOKEN` по [инструкции](docs/READ_TOKEN.md). Это личный API-токен GitVerse **только для чтения репозитория**. Никогда не вставляйте его значение в код или YAML.
6. **Вручную запустите `03 - Smartclass: verify Student CI run`** на своей ветке. Укажите `student_run_id` — номер успешного Student CI из URL страницы `/cicd/<ID>` (не ID job!). Получите `RESULT: PASS`.
7. **Сохраните ссылку на свой репозиторий и успешный запуск Smartclass** для проверки преподавателем. Если курс требует слияния ветки в `master`, сделайте это после успешной проверки и сохраните студенческую ветку и её историю.

## Что за три YAML

| Файл | Назначение | Редактировать студенту? |
| --- | --- | --- |
| `.gitverse/workflows/generate-variant.yml` | Выдаёт задание после создания ветки | Нет |
| `.gitverse/workflows/student.yml` | Проверяет проект, формирует и передаёт артефакт | **Да, только выделенные TODO и связанные рабочие шаги** |
| `.gitverse/workflows/smartclass.yml` | По ID проверяет успешность указанного Student CI через GitVerse API | Нет |
