# Отдельное задание: секрет `READ_TOKEN` в GitVerse

## Зачем это нужно

В финале практики вы вручную запускаете `smartclass.yml` и указываете ID успешного запуска своего `student.yml`. Преподавательский workflow обращается к GitVerse API, чтобы подтвердить, что указанный запуск относится к вашей ветке и завершился успешно. Для чтения этих данных нужен API-токен.

**Это отдельный шаг.** На этом этапе не требуется изменять `student.yml`, писать Python-код или добавлять запросы к API в студенческий CI. YAML вы исправляете в другой части практики.

## Что сделать

1. Создайте в своём GitVerse токен с минимальными правами: **Чтение репозитория** (дополнительных разрешений не требуется). Выбирайте ограниченный срок действия, если интерфейс позволяет.
2. Откройте **свой репозиторий** → **Настройки** → **Секреты и переменные** → добавление секрета.
3. Укажите имя **`READ_TOKEN`** (точно в таком написании), а значение — созданный токен. Это *секрет*, не обычная переменная.
4. После того как получите успешный запуск `student.yml`, скопируйте ID запуска из страницы CI/CD (число после `/cicd/`, а не ID отдельной job).
5. Переключитесь на свою ветку `student/<логин>` и вручную запустите `03 - Smartclass: verify Student CI run`, указав `student_run_id`.
6. Убедитесь, что в логах появилось `RESULT: PASS`.

## Что нельзя делать

- Не коммитьте токен в `README`, `TASK.md`, YAML, Python-код или JSON.
- Не публикуйте его в логах, скриншотах или артефактах. Не вставляйте токен в `echo`.
- Не используйте чужой или преподавательский токен.
- Не создавайте секрет с именем `GITVERSE_READ_TOKEN`: префикс `GITVERSE_` зарезервирован GitVerse.

## Диагностика

| Сообщение | Что проверить |
| --- | --- |
| `Missing READ_TOKEN` | Создан ли именно секрет `READ_TOKEN` в этом репозитории |
| `HTTP 401` или `HTTP 403` | Токен и его права на чтение репозитория |
| `HTTP 404` | ID запуска и репозиторий |
| `Run belongs to another branch` | Запуск Smartclass из правильной студенческой ветки |
| `Student CI did not finish successfully` | Указан завершённый зелёный запуск `student.yml` |

Ссылки: [секреты и переменные GitVerse](https://gitverse.ru/docs/cicd/docs/secrets-and-variables/), [API конкретного запуска](https://gitverse.ru/docs/developers/public-api/actions/api-get-repos-actions-runs-run_id).
